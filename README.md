# Spaceship Shooter

A fast-paced color-matching space shooter.

Match the color of your bullets with falling enemies to destroy them. Build combos, collect power-ups, and defeat bosses as you travel through different galaxies.

## How to Play

- **Move**: Slide left / right (or use mouse)
- **Shoot**: Automatic
- **Rule**: Only bullets that match the enemy’s color can destroy it
- Build combos for higher scores
- Collect power-ups: Shield, Time Slow, Multi-Shot, Extra Life
- Defeat bosses every few levels

## Features

- Color-matching combat
- Combo system
- Multiple enemy types (Normal, Fast, Tough, Splitter)
- Boss fights
- Power-ups
- Procedural sound effects
- High score saving
- Mobile-friendly
